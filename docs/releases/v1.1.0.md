# HypnoTech 1.1.0

HypnoTech 1.1.0 adds interchangeable relational persistence while retaining MongoDB
and the stable public API introduced in 1.0. It completes the original provider-neutral
architecture planned when the engine was created.

## Highlights

- Shared, async EF Core 10 repository implementations for CMS, Common, Ecommerce, and
  Media, with no concrete database driver in the shared projects.
- Thin PostgreSQL and SQL Server adapters, allowing a normal consumer to reference
  only its selected driver.
- Automatic startup migrations followed by ordered application seeders, with an
  explicit opt-out for deployment pipelines that manage schema changes separately.
- Provider-neutral inherited contract suites covering CMS and module repositories,
  ordering, nested values, identifiers, search, paging, seeding, and database lifecycle.
- Real Testcontainers coverage against PostgreSQL 18.1 and SQL Server 2022 CU22 GDR1,
  alongside the existing MongoDB 4.0.3, 8.0.32, and 9.0.4 matrix.
- A readable runtime provider switch in the Lantern House example, provider-specific
  Admin migrations, an independent Website read context, and a one-command Podman
  launcher for MongoDB, PostgreSQL, or SQL Server.
- Focused Chromium journeys for both relational providers while the complete
  Chromium, Firefox, and WebKit suite continues to run against MongoDB.

## Compatibility

This is a backward-compatible feature release from the public 1.0 API. MongoDB remains
the default provider; its collection names, BSON member names, routes, and tested
production compatibility baseline are unchanged. Existing production consumers remain
on `support/legacy-production` and do not require a database or engine migration.

Admin/CMS and public Website mappings remain intentionally independent. Applications
own their concrete `DbContext` types and migrations because their CMS models contribute
to the relational schema. MySQL/MariaDB and NHibernate remain deferred until a concrete
consumer justifies the additional provider surface.

## Verification

The release candidate passed the 39-project Release build with zero warnings or errors,
the formatting gate, 124 aggregate unit/architecture/MongoDB/relational/example/browser
tests, provider-specific PostgreSQL and SQL Server browser journeys, and the complete
hosted CI matrix across Linux, Windows, macOS, Chromium, Firefox, and WebKit. CodeQL
analysis passed for C#, JavaScript/TypeScript, and GitHub Actions.

## Distribution

This release is distributed as source through GitHub. Public NuGet packages remain
deferred until the separate package audit, local-feed rehearsal, and Trusted Publishing
plan are complete.
