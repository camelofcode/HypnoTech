# HypnoTech 1.0.0

HypnoTech 1.0.0 is the first stable public release of the reusable engine. It turns a
production-proven private codebase into a documented, tested portfolio baseline while
preserving the unchanged live-site source on `support/legacy-production`.

## Highlights

- Convention-driven generic CMS controllers, forms, tables, uploads, validation,
  search, ordering, duplication, child models, and select lists.
- Common, Ecommerce, Media, Frontend, and MongoDB modules with async-only public I/O
  contracts and request cancellation.
- Original Lantern House Admin and Website applications with synthetic seed data,
  responsive rendering, partial-page navigation, persistent player and basket,
  calculation-only checkout, and blocked payment side effects.
- xUnit unit, architecture, MongoDB 4.0/8.0/9.0 contract, example integration, and
  Playwright Chromium/Firefox/WebKit coverage.
- Standard free GitHub-hosted CI runners plus informative Windows/macOS builds.
- Public repository guidance and workflow-backed agent skills for compatibility,
  async request paths, tests, external HTTP doubles, and verification.

## Compatibility and breaking changes

The public 1.0 API is newer than the preserved production baseline. Repository and
I/O-bound service contracts are async-only, project paths are organised by module, and
the public example establishes an explicit Admin/Website dependency boundary. Existing
production consumers should not switch from `support/legacy-production` without a
planned migration and their own regression testing.

MongoDB.Driver 3.4.3 remains compatible with the live MongoDB Server 4.0.3 baseline.
The same repository contracts run against MongoDB 8.0.32 and 9.0.4. Linux is the
supported production platform; Windows and macOS results are portability signals.

## Distribution

This release is distributed as source through GitHub. Public NuGet packages are
deliberately deferred until the package graph, metadata, local-feed consumers, and
Trusted Publishing workflow pass the separate packaging plan.
